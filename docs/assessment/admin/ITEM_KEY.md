## Part A: Listening Comprehension

### Task A1: Spoken Comprehension (3 items)
1. **Clip 1 (Everyday Spoken English)**: **[b] Get a cup of water**
   - *Distractor Rationale*: [a] reflects misunderstanding *out of order*; [c] confuses *cup* with buying; [d] confuses *water* with washing.
2. **Clip 2 (General Workplace Schedule)**: **[b] Tuesday at 10:00 AM**
   - *Distractor Rationale*: [a] falls for the contrastive distractor *not Thursday*; [c] introduces false afternoon time; [d] combines false day and time.
3. **Clip 3 (Workplace Problem Report — Contextual Probe)**: **[b] The database login credentials expired at midnight**
   - *Distractor Rationale*: [a], [c], [d] are plausible technical causes not mentioned in the audio.

### Task A2: Micro-Dictation / Bottom-Up Decoding (4 items)
1. **Sentence 1**: Target: *"Can you send me the file?"*
   - *Acceptable*: Punctuation/capitalization ignored. Exact words required: *can you send me the file*.
   - *Partial (0.5 pt)*: Missed functional word (e.g., *can you send me file*).
2. **Sentence 2**: Target: *"What did you do yesterday?"*
   - *Acceptable*: *What did you do yesterday?* (Assimilated pronunciation [wʌdʒə] must be recognized).
3. **Sentence 3**: Target: *"I've been working on this bug."*
   - *Acceptable*: *I've been working on this bug* OR *I have been working on this bug*.
4. **Sentence 4**: Target: *"There's a problem with the server."*
   - *Acceptable*: *There's a problem with the server* OR *There is a problem with the server*.

### Optional Task A3: Advanced Acoustic Parsing Extension
- **Target Criterion**: Explaining that redundant consumer instances were created unnecessarily because the team lacked visibility into the fact that the upstream broker was throttling the event stream. (Award credit if core semantic causal link is captured in English or Portuguese).

### Task D2: Articulatory Production (Audio Evaluation Targets)
Evaluator listens to `spoken_d2.m4a` and checks for 4 candidate Brazilian Portuguese interference features:
1. *Stop Epenthesis*: Insertion of [i] or [ɪ] after final consonants in *stop*, *laptop*, *big*.
2. *Vowel Laxing*: Failure to distinguish lax /ɪ/ in *live* [lɪv] from tense /iː/ in *eat* [iːt].
3. *Word Stress & Reduction*: Stress on second syllable in *de-VEL-op-ment* [dɪˈvɛləpmənt] and first syllable in *DA-ta-base* [ˈdeɪtəbeɪs].
4. *Nasal Closure*: Bilabial lip closure on *come* /kʌm/, alveolar tongue closure on *plan* /plæn/ and *afternoon* /ˌæftɚˈnuːn/.

## Part E: Written Composition

### Task E1: Sentence Combining (Target Models)
1. Pair 1:
   - *Target*: *"Because the database was very slow, we optimized the query index."* OR *"We optimized the query index because the database was very slow."* OR *"Since the database was very slow..."*
2. Pair 2:
   - *Target*: *"Alex pushed the code to the repository after the automated checks passed successfully."* OR *"When the automated checks passed successfully, Alex pushed..."* OR *"After the automated checks passed successfully, Alex pushed..."*
3. Pair 3:
   - *Target*: *"Although I wanted to attend the conference yesterday, I had too many urgent deadlines at work."* OR *"I wanted to attend the conference yesterday, but I had too many urgent deadlines at work."*

### Task E2: Functional Workplace Message (3 Evaluation Criteria)
1. *Context / Current Task*: Explicitly mentions current project/task in progress.
2. *Discrepancy / Problem*: Describes error, anomaly, or discrepancy found.
3. *Call to Action / Meeting Request*: Politely asks for 10 minutes to review together.
